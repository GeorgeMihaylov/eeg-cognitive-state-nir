# Предобработка EEG для офлайн-обучения

Модуль `offline.py` объединяет методы, которые повышают устойчивость признаков и
моделей к дрейфу, плохим каналам, сетевой наводке и глазодвигательным артефактам.
Пайплайн сохраняет число отсчётов, поэтому разметка остаётся выровненной с EEG.

## Рекомендуемый базовый порядок

1. Полиномиальный детрендинг удаляет медленный дрейф и постоянную составляющую.
2. Нулефазовая полосовая и notch-фильтрация не вносит фазовую задержку.
3. Устойчивый средний референс сначала оценивает референс через медиану, находит
   плохие каналы и исключает их из среднего. Это не даёт одному шумному электроду
   загрязнить все остальные каналы.
4. Плохие каналы заменяются средним хороших каналов. Если известны координаты
   электродов, в дальнейшем предпочтительна сферическая сплайн-интерполяция.
5. EOG-регрессия, ICA и вейвлет-денойзинг применяются только при наличии оснований
   и сравниваются абляцией на validation-наборе.

```python
from cogstate.preprocessing import (
    OfflinePreprocessingConfig,
    OfflinePreprocessingPipeline,
    WaveletDenoisingConfig,
)

config = OfflinePreprocessingConfig(
    sample_rate=256,
    # Для модели, которая будет работать в streaming, использовать causal.
    filter_mode="causal",
    # Опционально; сначала сравнить с вариантом без wavelet_config.
    wavelet_config=WaveletDenoisingConfig(
        wavelet="sym8", threshold_method="bayes", threshold_mode="soft"
    ),
)
result = OfflinePreprocessingPipeline(config).transform(eeg)
clean_eeg = result.values
print(result.report)
```

`filter_mode="zero_phase"` подходит для чисто офлайн-анализа. Для обучения
потоковой модели нужен `filter_mode="causal"`: он использует ту же инициализацию
и те же состояния фильтров, что и `StreamingFilter`. Состояние начинается заново
для каждой независимой записи; фрагменты одной записи нельзя фильтровать как
несвязанные окна.

Если записываются EOG-каналы, регрессор обучается только на тренировочной или
отдельной калибровочной записи и затем фиксируется:

```python
config = OfflinePreprocessingConfig(sample_rate=256, use_eog_regression=True)
pipeline = OfflinePreprocessingPipeline(config)
pipeline.fit(train_eeg, eog=train_eog)

train_clean = pipeline.transform(train_eeg, eog=train_eog).values
validation_clean = pipeline.transform(validation_eeg, eog=validation_eog).values
```

## Ограничения и проверка качества

- Детрендинг, фильтрация и референс не используют целевые метки. EOG-регрессию,
  ICA, scaler, selector и другие обучаемые преобразования нужно `fit`-ить внутри
  каждого train-fold, не на полном датасете.
- EOG-регрессия удаляет линейную часть сигнала, общую с EOG. Она может удалить и
  настоящую фронтальную EEG-активность, поэтому выключена по умолчанию.
- Вейвлет-порог полезен при широкополосном шуме, но способен сгладить информативные
  детали. Он также выключен по умолчанию; параметры выбираются только по
  validation-метрике и стабильности между испытуемыми.
- Отбрасывание эпох не входит в этот continuous-пайплайн. Полный пакетный контур
  находится в `MNEFasterCalibrator`; возвращаемую `kept_epoch_mask` необходимо
  применить к целевым меткам.
- Упрощённая интерполяция не учитывает геометрию монтажа. Она переносима между
  гарнитурами, но уступает сферическим сплайнам при наличии координат электродов.

Методологическая основа: устойчивое референсирование и обработка плохих каналов
описаны в [PREP pipeline](https://pmc.ncbi.nlm.nih.gov/articles/PMC4471356/) и в
[работе по robust rereferencing](https://pmc.ncbi.nlm.nih.gov/articles/PMC4160811/).
Риск удаления нейронной активности регрессией EOG обсуждается в
[сравнении регрессии и component-based correction](https://doi.org/10.1016/j.ijpsycho.2004.03.007).
