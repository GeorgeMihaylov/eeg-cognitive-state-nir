# Вложенный выбор коэффициента вспомогательной CORN-задачи

## Статус

Реализована инфраструктура этапа 7Г-2. Полный эксперимент на ЭЭГ в этой копии не запускался.

## Протокол

Для каждой комбинации группы признаков, seed и внешнего разбиения обучаются три модели `categorical_corn` с коэффициентами `0.25`, `0.5` и `1.0`.

Матрица:

- группы признаков: `eeg_pow`, `eeg_only`;
- seeds: `7`, `42`, `123`;
- внешние разбиения: `1..5`;
- коэффициенты: `0.25`, `0.5`, `1.0`;
- всего: 90 обучений кандидатов и 30 итоговых внешних оценок.

Все три кандидата одной комбинации используют одно внешнее обучающее множество, одно внутреннее проверочное разбиение, один порядок признаков и одну область нормализации.

## Выбор коэффициента

Кандидат сначала должен удовлетворять ограничению:

`validation BA >= categorical baseline validation BA - 0.0100`.

Среди допустимых кандидатов последовательно минимизируются:

1. доля тяжёлых ошибок;
2. порядковая средняя абсолютная ошибка;
3. коэффициент вспомогательной задачи.

При отсутствии допустимых кандидатов соответствующее внешнее разбиение завершается без вычисления внешних тестовых прогнозов.

## Защита внешней тестовой части

Кандидаты сохраняют только:

- checkpoint;
- журнал обучения;
- внутренние проверочные прогнозы;
- внутренние проверочные метрики;
- описание внутреннего разбиения;
- параметры нормализации;
- разрешённую конфигурацию и manifest.

После формирования решения выбранный checkpoint строго загружается заново. Только после этого вычисляются прогнозы на внешней тестовой части. Для двух отклонённых кандидатов внешние прогнозы не создаются.

## Совместимость с инфраструктурой

Эксперимент использует:

- существующий `build_model`;
- `TorchClassificationAdapter.fit()` и его раннюю остановку по `validation_categorical_loss`;
- существующее внутреннее разбиение по `record_group_id`;
- существующие функции метрик;
- checkpoints формата задачи 7Б;
- категориальные внутренние проверочные артефакты задачи 7Г-1.

Новый цикл оптимизации не реализован. Оркестратор только вызывает стандартный адаптер для каждого кандидата.

## Артефакты

Кандидаты:

`benchmark_results/auxiliary_corn_nested_lambda/candidates/<group>/seed_<seed>/fold_<fold>/lambda_<value>/`

Выбранные внешние результаты:

`benchmark_results/auxiliary_corn_nested_lambda/selected/<group>/seed_<seed>/fold_<fold>/`

Объединённые внешние прогнозы по пяти разбиениям:

`benchmark_results/auxiliary_corn_nested_lambda/selected/<group>/seed_<seed>/outer_test_predictions.parquet`

Итоговые отчёты после запуска:

- `reports/auxiliary_corn_nested_lambda_results.md`;
- `reports/auxiliary_corn_nested_lambda_results.json`.

## Возобновление

Режим `--resume` повторно использует кандидат только при совпадении хеша конфигурации и наличии checkpoint и внутренних проверочных артефактов. Итоговая внешняя оценка повторно используется только при совпадении выбранного коэффициента и наличии внешних predictions и metrics.

## Проверки

Добавлены тесты:

- строгой проверки YAML-протокола;
- маршрутизации через общий CLI;
- матрицы из 90 обучений;
- обучения трёх синтетических кандидатов;
- выбора по внутренней проверочной части;
- отсутствия внешних predictions в каталогах кандидатов;
- создания внешних predictions только в каталоге выбранной модели.

Целевой набор: 48 тестов успешно, 1 прежнее предупреждение scikit-learn.

Расширенная регрессионная проверка фабрики, runner, последовательностей и порядковой инфраструктуры: 108 тестов успешно, 3 пропущены средой.
